% ---------- INTRODUCTION ----------
\section{Introduction}
\textbf{Cricket} is the most popular sport played all over the world. It requires physical skills, continuous practice, and an awareness of techniques. Traditional training systems require a physical setup, coaches, and some other resources that often limit players to practice effectively.

With the advancement of technology, the sports training system has been changed to simulation and other tools. The purpose of this project, \textbf{Namal Criko}, is to provide a platform where players can learn different types of batting and bowling techniques by simulations.


Through this, players can experience different styles of bowling such as spin, fast, and slow deliveries, and also batting techniques (drive, sweep, and defensive shots, etc.) in a simulated environment.The main goal of this system is to provide knowledge of cricket techniques in a controlled and engaging environment. The system will provide training aid, especially to students and cricket lovers at \textbf{Namal University} who wish to improve their cricket knowledge and techniques using technology.

% ---------- PROBLEM STATEMENT ----------
\section{Problem Statement}
In Namal, many students play cricket regularly, yet there isn’t any proper system or structured guide to help them learn or practice the correct techniques of batting, bowling, and fielding. Most players rely on personal experience or random practice, which limits their learning. As of now, there is no digital or visual platform that explains how each technique should actually be performed. Because of this, learners find it difficult to understand the correct movements, timing, and form. Therefore, there is a need for an application that can simulate different cricket techniques and make learning easier and more effective.

% ---------- PROJECT OBJECTIVES ----------
\section{Project Objectives}
The objectives of the project are:
\begin{enumerate}[label=\arabic*.]
    \item A user-friendly app that would show how various cricket techniques are executed, such as batting and bowling.


    \item To help learners understand the right body movements and timing through visual animations.


    \item Allow users to select any given shot or delivery for instance, a sweep shot or a Yorker-and watch step-by-step how it is done.


    \item Making the learning of cricket more interesting and fun with the help of computer-based simulations, rather than just reading or watching videos.

\section{Software Development Methodology}
We have adopted the \textbf{Agile (Scrum)} methodology for the development of \textbf{Namal Criko}. By utilizing 2-week sprints, we ensure that the complex 3D web simulations and administrative authorization workflows are developed iteratively with continuous feedback from the Requirement Provider (RP).

\textbf{Scrum-Based One-Year Development Plan (Dec 2025 – Nov 2026)}

\begin{longtable}{|p{3.5cm}|p{9.5cm}|}
\hline
\textbf{Phase / Sprint} & \textbf{Scrum-Aligned Description} \\ \hline

Product Backlog Creation  & 
Dec 2025: Collaborative sessions with the RP to define User Stories for the Player and Admin portals. Priority is given to defining the "Admin Approval" logic and 3D simulation sub-categories (Fast/Slow bowling). 
\\ \hline

Sprint 0: Setup  & 
Late Dec – Early Jan: Initializing the web environment using \textbf{React.js} and \textbf{Three.js}. Setting up the \textbf{Firebase Web SDK} for authentication and designing the dual-dashboard UI wireframes in Figma. 
\\ \hline

Sprints 1–3: Core Web Simulations & 
Jan – Mar 2026: Developing the 3D browser environment. Implementing basic player meshes, batting/bowling animations in Three.js, and ensuring the "Simulation + Written Description" layout is functional.
\\ \hline

Sprints 4–6: Advanced Mechanics  & 
Apr – Jun 2026: Expansion of simulation categories to include Fast, Swing, and Spin bowling variations. Implementing advanced batting styles and refining ball physics for a realistic web experience.
\\ \hline

Sprints 7–8: Admin \& User Systems  & 
Jul – Aug 2026: \textbf{Critical Phase:} Implementation of the \textbf{Admin Authorization Module} (Allow/Approve users). Development of the Player Performance Tracker (Run Rate, Matches) and the Admin-controlled Ad Management system.

Sep – Oct 2026: Optimizing 3D assets for low-latency web loading. Integrating the Help Section/Support Desk and conducting rigorous cross-browser testing (Chrome, Safari, Edge).

Final Sprint: Deployment  & 
Nov 2026: Final User Acceptance Testing (UAT) focusing on the Admin workflow and simulation accuracy. Deployment of the web application via Firebase Hosting or Vercel. 
\\ \hline

\end{longtable}
\section{Tools and Technologies}
For the development of \textbf{Namal Criko}, which is a web-based cricket training and simulation application, the following tools and technologies will be used. These tools are selected based on the requirements of 3D web rendering, browser performance, and secure administrative backend support.

\begin{itemize}

% Web Framework
\item \textbf{Web Framework: React.js} \\
React.js will be used to develop the core web application, providing a responsive and component-based architecture for the separate Player and Admin dashboards.

% Three.js for Web Simulation
\item \textbf{Web Simulation Engine: Three.js (WebGL)} \\
To facilitate 3D simulations within a browser environment, Three.js will be utilized. This allows for the rendering of complex ball trajectories and player mechanics without requiring users to download additional software.

% Blender for 3D modeling
\item \textbf{3D Modeling and Animation: Blender} \\
Blender will be used to design and animate 3D cricket assets, including players, stadiums, and equipment. These models will be exported in glTF/GLB formats for optimized web loading.

% Backend and Database
\item \textbf{Backend and Database: Node.js and MongoDB} \\
The backend will handle the Admin authorization logic, storage of player performance metrics (Run Rate, Matches), and the help-desk ticketing system.

% UI Design
\item \textbf{UI/UX Design: Figma} \\
Figma will be used to design the web interfaces, ensuring a seamless user experience for both the learning modules and the administrative control panels.

% Version Control
\item \textbf{Version Control: GitHub} \\
GitHub will be used for source code management, collaborative development, and maintaining project versions throughout the semester.

% Project Management
\item \textbf{Project Management: Zoom / Google Sheets} \\
These tools will be used for coordinating team meetings and tracking task progress under the Agile Scrum methodology.

\end{itemize}
