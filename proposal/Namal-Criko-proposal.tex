% ---------- INTRODUCTION ----------
\section{Introduction}
\textbf{Cricket} is the most popular sport played all over the world. It requires physical skills, continuous practice, and an awareness of techniques. Traditional training systems require a physical setup, coaches, and some other resources that often limit players to practice effectively.

With the advancement of technology, the sports training system has been changed to simulation and other tools. The purpose of this project, \textbf{Namal Criko}, is to provide a platform where players can learn different types of batting and bowling techniques by simulations.


Through this, players can experience different styles of bowling such as spin, fast, and slow deliveries, and also batting techniques (drive, sweep, and defensive shots, etc.) in a simulated environment.The main goal of this system is to provide knowledge of cricket techniques in a controlled and engaging environment. The system will provide training aid, especially to students and cricket lovers at \textbf{Namal University} who wish to improve their cricket knowledge and techniques using technology.

% ---------- PROBLEM STATEMENT ----------
\section{Problem Statement}
In Namal, many students play cricket regularly, yet there isn’t any proper system or structured guide to help them learn or practice the correct techniques of batting, bowling, and fielding. Most players rely on personal experience or random practice, which limits their learning. As of now, there is no digital or visual platform that explains how each technique should actually be performed. Because of this, learners find it difficult to understand the correct movements, timing, and form. Therefore, there is a need for an application that can simulate different cricket techniques and make learning easier and more effective.

% ---------- PROJECT OBJECTIVES ----------
\section{Project Objectives}
The objectives of the project are:
\begin{enumerate}[label=\arabic*.]
    \item A user-friendly app that would show how various cricket techniques are executed, such as batting and bowling.


    \item To help learners understand the right body movements and timing through visual animations.


    \item Allow users to select any given shot or delivery for instance, a sweep shot or a Yorker-and watch step-by-step how it is done.


    \item Making the learning of cricket more interesting and fun with the help of computer-based simulations, rather than just reading or watching videos.

\section{Software Development Methodology}
We have adopted the \textbf{Agile (Scrum)} methodology for the development of our project. 
Scrum divides the development process into short, fixed-length iterations called 
\textbf{sprints}, where each sprint includes requirement refinement, design, coding, testing, 
and review. This iterative approach allows continuous collaboration with the Requirement 
Provider (RP) and rapid adaptation to feedback.

\textbf{Scrum-Based One-Year Development Plan (Dec 2025 – Nov 2026)}

\begin{longtable}{|p{3cm}|p{10cm}|}
\hline
\textbf{Phase / Sprint} & \textbf{Scrum-Aligned Description} \\ \hline

Product Backlog Creation & 
Dec 2025: Conduct meetings with the RP to gather requirements, define epics and user stories, prioritize the product backlog, and set acceptance criteria. 
\\ \hline

Sprint 0 (Setup Sprint) & 
Late Dec – Early Jan: Project environment setup, Unity project initialization, Firebase backend setup, folder structure creation, initial architecture planning, and UI wireframe creation. 
\\ \hline

Sprints 1–3 (Core Simulation Mechanics) & 
Jan – Mar 2026: Three 2-week sprints. Implement basic player models, core batting and bowling animations, initial ball physics, and basic UI navigation. Each sprint includes planning, development, testing, review, and retrospective. 
\\ \hline

Sprints 4–6 (Advanced Simulation Features) & 
Apr – Jun 2026: Add multiple bowling variations (fast, spin, swing), advanced batting shots, refine physics, improve animations, optimize movements, and incorporate RP feedback after each sprint review. 
\\ \hline

Sprints 7–8 (User System \& Tracking) & 
Jul – Aug 2026: Implement Firebase authentication, user profile system, session tracking, performance analytics, and cloud storage. Testing and feedback integration occur after every sprint. 
\\ \hline

Sprints 9–10 (Polish \& Optimization) & 
Sep – Oct 2026: UI polishing, performance optimization for mobile devices, bug fixing, model improvements, UI/UX refinement, and preparation of the release candidate. 
\\ \hline

Final Sprint (Release Sprint) & 
Nov 2026: Final system testing, user acceptance testing with the RP, preparation of documentation, final build creation, and deployment. 
\\ \hline

\end{longtable}


% ---------- TOOLS AND TECHNOLOGIES ----------
\section{Tools and Technologies}
For the development of \textbf{Namal Criko}, which is a mobile-based cricket training and simulation application, the following tools and technologies will be used. These tools are selected based on the requirements of 3D simulation, mobile performance and backend support.


\begin{itemize}


% Unity for Mobile Simulation
\item \textbf{Mobile Development / Simulation Engine: Unity 3D} \\
Unity provides a powerful physics engine, animation system, and mobile export support for both Android and iOS. It is ideal for creating cricket simulations such as ball trajectories, bowling animations, and batting mechanics.


% Blender for 3D modeling
\item \textbf{3D Modeling and Animation: Blender} \\
Blender will be used to design and animate 3D cricket players, bat, ball, stadiums, and different bowling/batting styles.

% Firebase backend
\item \textbf{Backend and Database: Firebase (Authentication, Firestore, Storage)} \\
Firebase ensures real-time synchronization, secure login, cloud-based data storage, and scalability suitable for a mobile app.


% UI Design
\item \textbf{UI/UX Design: Figma} \\
Figma will be used to design mobile app screens, user flows, menus, and interface components.


% Version Control
\item \textbf{Version Control: GitHub} \\
GitHub will be used for source code management, collaboration, issue tracking, and version maintenance.


% Project Management
\item \textbf{Project Management: Zoom / Google Sheets} \\
These tools will help track tasks, sprints, documentation, and weekly progress under the Agile Scrum methodology.


\end{itemize}
