SRS Documentation: Namal Criko
This directory contains the official Software Requirements Specification (SRS) for the Namal Criko project. The document is developed following the IEEE Standard 830-1984 to ensure professional quality and technical consistency.

📂 Folder Structure
Namal_Criko_SRS.tex: The complete LaTeX source code for the SRS document.

Namal_Criko_SRS.pdf: The final, compiled version of the SRS.

/images: This sub-folder contains all diagrams and assets embedded in the SRS, including:

context_diagram.png: High-level system interaction.

level1_dfd.png: Detailed process-level data flow.

use_case_diagram.png: Visual representation of actor actions.
